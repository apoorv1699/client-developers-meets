# Client Developers Meets

A Spring Boot web application for facilitating meetings between clients and developers.

## Features

- User authentication with separate login pages for clients and developers
- Static web interface with HTML, CSS, and JavaScript

## Prerequisites

- Java 21
- Maven 3.6 or higher

## Getting Started

1. Clone the repository
2. Navigate to the project directory
3. Run the application:

```bash
mvn spring-boot:run
```

The application will start on `http://localhost:8080`

## Project Structure

- `src/main/java`: Java source code
- `src/main/resources/static`: Static web assets (HTML, CSS, JS)
- `src/main/resources/templates`: Thymeleaf templates (if used)
- `pom.xml`: Maven configuration
